# saboteso-bot

AIが生成した大喜利をX（@saboteso_）へ1日1回自動投稿することを目指すTypeScriptアプリです。
現在はフェーズ0-C（ローカルでのTypeScript実行・型チェック環境）までの実装です。

## 初期仕様（目標）

- 大喜利専用・文章のみ
- 通常ポストのみ（自動返信なし）
- 1日1回の自動投稿
- キャラクターは脱力系・丁寧語・少し間が抜けている
- 主目的は収益化の実験

## 実装済み

- TypeScript・tsxによるローカル実行環境
- 起動メッセージを表示する `src/index.ts`
- TypeScriptの型チェック用コマンド
- `.env` などをGit管理から除外する設定

## 未実装

- AIによる大喜利生成
- X APIとの連携・投稿
- 1日1回のスケジュール実行
- API認証情報の読み込み
- 投稿履歴の管理・重複投稿防止・エラー処理
- 自動テスト（既存の `npm test` は未設定のため失敗します）

生成方法、利用API、実行基盤などの未決定事項は、今後確認してから実装します。

## ローカル実行

Node.jsとnpmが必要です。今回の動作確認環境はNode.js v25.8.0 / npm 11.11.0です。

```sh
npm ci
npm run dev
npm run typecheck
```

`npm run dev` は起動メッセージを表示して終了します。
`npm run typecheck` はJavaScriptを出力せずに型を検査します。
現在のコードは外部APIへの通信やXへの投稿を行わず、APIキーも不要です。
秘密情報をコードやGit管理対象のファイルに記載しないでください。
